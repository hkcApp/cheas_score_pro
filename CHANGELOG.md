# Changelog

## 2.7.8

- Updated default base-point values and migrated previously shipped defaults
  while preserving customized scoring values.
- Added tap-to-view descriptions for scoring categories, patterns, and Mahjong
  outcomes, with dialogs sized for mobile screens.
- Renamed Nine Gate to Nine Gates.

## 2.7.7

- Corrected round scoring to calculate base points as quantity multiplied by
  point value.
- Added a 5-point Mahjong bonus value to the score table.
- Updated self-draw scoring: each other active player loses 5 points, and the
  winner receives 5 points per other active player.
- Updated discarded-chip scoring: each other active player loses 5 points per
  other active player, and the winner receives that bonus once.
- Updated round history to show each player's score change.
